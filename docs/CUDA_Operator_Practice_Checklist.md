## 3. 每题统一验收标准

- 正确性：包含最小尺寸、非整齐尺寸、常见尺寸、大尺寸及该算子的特殊输入。
- 数值：明确 dtype、累加精度、参考公式、绝对/相对误差容限；容限应随 dtype 与累加长度合理设置，不能为通过测试任意放宽。
- 内存安全：优先跑 memcheck；涉及 shared memory 和同步时补充 racecheck/synccheck。工具通过不等于证明所有并发问题都不存在。
- 计时：建议先预热 20 次，再多轮测量；可按算子时长调整次数，记录每轮重复数与中位数/波动。
- 对照：相同输入、dtype、输出语义与计时边界；原地算子需要在迭代间正确恢复输入。
- 性能解释：提出假设，一次改变一项，记录证据；没有加速也是有效结果。

有效带宽可记为 `(算法读取字节数 + 写入字节数) / 时间`，它不等于实际 DRAM 流量；GEMM 吞吐可按 `2*M*N*K / 时间` 计算。统一标注 GB/s 或 TFLOP/s、时间单位和计算口径。
